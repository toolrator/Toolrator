## Reporting a Vulnerability

If you discover a security vulnerability in any Toolrator package, **please report it responsibly**.

### 📧 Contact

Email: **security@toolrator.com**

### ⚠️ Please Do NOT

- Open a public GitHub issue for security vulnerabilities
- Disclose the vulnerability publicly before we have had a chance to address it

### What to Expect

- **Acknowledgment**: We will acknowledge your report within **48 hours**
- **Assessment**: We will assess the severity and impact within **5 business days**
- **Fix**: Critical vulnerabilities will be prioritized for immediate patching
- **Credit**: We will credit you in the release notes (unless you prefer to remain anonymous)

### What to Include

When reporting, please include:
- A description of the vulnerability
- Steps to reproduce (if applicable)
- The affected package(s) and version(s)
- Any potential impact assessment

Thank you for helping keep Toolrator and its users safe.
